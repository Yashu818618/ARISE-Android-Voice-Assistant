# ARISE – Android Voice Assistant

ARISE (formerly "Igris") is an Android voice assistant app with a Solo Leveling-inspired red neon UI.

> **Note:** This project was built completely using AI-assisted development. I am using it to learn how Android apps are structured (Kotlin, Jetpack Compose, networking), and I am studying the code part by part.

## Features
- Voice recognition
- Text-to-speech responses
- Server communication using Retrofit (REST API calls)
- Settings screen with navigation
- Custom fonts and immersive (sticky) full-screen mode

## Tech Stack
- Kotlin
- Jetpack Compose
- Retrofit
- Android Studio

## App Details
- Package name: `com.yashu.igris`

## How to Run
1. Clone this repository: `git clone https://github.com/Yashu818618/ARISE-Voice-Assistant.git`
2. Open the project in Android Studio.
3. Let Gradle sync finish.
4. Run on an emulator or a physical Android device.
